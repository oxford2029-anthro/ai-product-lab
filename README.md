# AI Product Lab｜AI 产品实验室

这是我的 AI 产品实践与思考作品集。

我主要记录如何从真实问题出发，使用 ChatGPT、Codex 等 AI 工具完成需求梳理、产品设计、原型开发与迭代，并总结人与 AI 在其中的分工、模型局限和产品判断。

## 项目

### 01 Semester Flow｜个人学期工作流

一个基于真实个人需求设计的学期管理 Web 原型。

我希望解决课程、任务、截止日期、弹性工作与每日计划分散在不同平台的问题，因此尝试将它们整合为一个动态工作流。

**我的工作**
- 定义真实需求与使用场景
- 梳理产品逻辑和信息架构
- 使用 ChatGPT 拆解需求
- 使用 Codex 完成 Web 原型
- 根据真实使用反馈持续迭代

**AI 工具**
ChatGPT · Codex

**关键词**
AI 产品设计 · Vibe Coding · Workflow Design · Human-AI Collaboration
